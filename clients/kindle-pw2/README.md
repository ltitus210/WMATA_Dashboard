# WMATA Dashboard for Kindle Paperwhite 2

This is the Kindle counterpart to the NOOK dashboard app. It is a KDK 2.x
Kindlet for a jailbroken Paperwhite 2 running firmware 5.8.10.

## Install

1. Keep the Kindle in Airplane mode while copying files over USB.
2. Copy `dist/WMATA-Dashboard-PW2-v1.7.azw2` into the Kindle's `documents` folder.
3. Safely eject and unplug the Kindle.
4. Turn Wi-Fi on, open the local Library view, and tap **WMATA Dashboard**.

The default dashboard is:

```text
http://192.168.0.10:8080/eink/home/kindle-pw2/
```

The URL, refresh interval, and full-refresh cadence can all be changed in the
app. A gallery URL ending in `/`, a manifest URL, or a direct PNG URL is
accepted. Settings are stored on the Kindle at:

```text
/mnt/us/extensions/wmata-dashboard/dashboard.properties
```

## Controls

- **Save & Start Dashboard** starts continuous updates.
- **Close Menu & Resume Dashboard** applies the visible settings and resumes.
- **Show One Frame** downloads one frame without starting the update loop.
- Tap the bottom footer or the narrow right edge to advance a page.
- Tap the narrow left edge to go to the previous page.
- Tap anywhere else to stop updates and reopen the menu.
- Page navigation wraps between the first and last manifest page.
- If a download fails, the menu displays the error, retries automatically, and
  offers **Retry Now**.

While the dashboard is running, the app asks `powerd` to keep the display awake.
It restores normal sleep behavior when stopped or closed. The app uses FBInk,
when available, only to request the configured periodic full refresh; image
painting itself remains inside the Kindlet.

## Build

The checked-in `lib/jailbreak.jar` and `developer.keystore` come from the
official KUAL project and provide the same Kindlet jailbreak/signing mechanism
as KUAL. They are intentionally not generated by this project.

With a Java 8 JDK installed:

```sh
JDK_HOME=/path/to/jdk8/Contents/Home ./build.sh
```

The build emits `dist/WMATA-Dashboard-PW2-v1.7.azw2`. The source is Java 1.4
compatible and the resulting class files use Java class-file version 48 for
compatibility with the Kindle JVM.
